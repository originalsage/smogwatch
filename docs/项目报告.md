# SmogWatch 项目报告

## 1. 项目背景与目标
雾霾频繁出现会影响出行和健康。本项目实现手机端优先的雾霾探测系统，用户可在出行前查看天气和空气质量并获取健康建议。

## 2. 技术选型
- 前端：Vue3 + Vite + Axios + HTML5 响应式布局
- 后端：Spring Boot + MyBatis + MySQL
- 外部接口：百度 IP 定位 API、百度天气 API

## 3. 系统架构
1. 前端发起自动定位或手动选城。
2. 后端写入定位记录。
3. 后端调用百度天气接口获取天气与空气质量。
4. 数据返回前端展示，同时写入数据库形成历史快照。

## 4. 数据库设计
### city_location_log
- 用途：记录定位来源（IP/手动）及城市信息。
- 关键字段：`source, province, city, district, adcode, longitude, latitude, created_at`

### weather_snapshot
- 用途：记录天气与空气质量快照，支持历史分析。
- 关键字段：`city_name, temp, humidity, weather_text, aqi, pm25, observed_at, raw_json`

## 5. 核心功能实现
### 5.1 定位功能
- 自动定位：后端调用百度 IP 定位接口。
- 手动选城：用户输入城市名或区县编码。
- 异常处理：网络失败、参数错误时返回友好提示。

### 5.2 天气与空气质量
- 支持基础字段展示：温度、体感、湿度、风力、风向、天气现象。
- AQI 及 PM2.5 等字段采用可用即展示策略。
- 若高级字段缺失则自动降级并展示提示。

### 5.3 移动端界面
- 使用 Flex/Grid 实现自适应布局。
- AQI 使用进度条和分级文案进行可视化。

## 6. 接口说明
- `POST /api/location/resolve`
- `POST /api/location/manual`
- `GET /api/weather/current?city=...`
- `GET /api/weather/history?city=...&date=YYYY-MM-DD`

## 7. 测试记录
- 正常路径：自动定位、手动选城、天气展示、AQI 展示、历史查询。
- 异常路径：百度接口失败、超时、字段缺失、参数非法。
- 结果：系统可在基础字段可用条件下稳定运行；高级字段缺失时可优雅降级。

## 8. 已知限制与优化方向
- 当前天气接口按请求实时拉取，可增加缓存和限流策略。
- 可加入定时任务形成时间序列数据，支持图表分析。
- 可扩展多数据源兜底（和风、墨迹）以提升可用性。
